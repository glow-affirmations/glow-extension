# Change Log

## 0.1.5

### Native Community updates and minor UX improvements

- Added native Community joining, profile editing, affirmation sharing, reporting, and blocking so these flows stay inside VS Code.
- Added deterministic membership refresh and authoritative feed reconciliation after Community changes.
- Fixed the account dropdown being clipped at compact editor widths.
- Refined the audio and appearance controls with clearer binaural-beat presentation, headphone indicators, “Loop pause” copy, and a simpler theme menu.

## 0.1.4

- Added the native Glow community with shared affirmations and realtime channel chats.
- Added message selection, bulk deletion continuity, and Telegram-style read receipts.
- Added the Premium lifetime-offer handoff for eligible users.
- Refined account pairing, offline behavior, dashboard tabs, chat composition, and binaural-beat controls.
- Updated the default affirmation and refreshed the landing-page feature demonstrations.
- Open-sourced the device-side extension under GPL-3.0-or-later with a verifiable release-artifact workflow.

## 0.1.3

- Added the Premium Discord community invitation to the native dashboard.

## 0.1.2

- Changed the Glow extension from the MIT License to the proprietary Glow
  Extension End User License Agreement.

## 0.1.1

- Restored the dimensional Blender-rendered Glow mark for Marketplace and
  large onboarding presentation.
- Refined the Marketplace product preview to match the extension interface.
- Added a native listening dashboard that opens beside your code.
- Added direct browser and billing actions to the native dashboard.
- Matched the dashboard structure and typography across Glow's editor and web
  experiences.
- Opened the custom affirmation composer for new Premium libraries.
- Simplified the custom affirmation creation status.
- Added two distinct recordings for every custom affirmation, with an
  in-editor preview and choice before the affirmation enters the library.
- Made regeneration non-destructive so the current recording remains active
  until a replacement recording is chosen.
- Restored interrupted recording choices after reopening Glow and removed the
  old Premium ten-generations-per-hour product limit.
- Refreshed older voice copy so it describes Glow rather than a named voice.

## 0.1.0

- First public Visual Studio Marketplace release.
- Added the Featured, Favorites, and Custom affirmation libraries.
- Added GitHub account connection and cross-device library sync.
- Added custom affirmation generation and Premium entitlement support.
- Added listening progress sync and dashboard integration.
- Added light, dark, and editor-following themes.
- Added resilient offline playback and background account refresh.
