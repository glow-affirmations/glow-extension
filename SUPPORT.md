# Support

- Product, account, and billing support: [support@justglow.dev](mailto:support@justglow.dev)
- Reproducible extension bugs and feature requests: use the repository issue templates
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md)

Please include the extension version, VS Code or compatible editor version,
operating system, reproduction steps, and relevant sanitized logs. Never post
tokens, credentials, private affirmation content, or personal account data.
